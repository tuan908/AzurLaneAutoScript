# Architecture governance

Ongoing, incremental work to keep the code this fork owns small, single-sourced and
machine-checked. Read in this order:

- [progress.md](progress.md): what each round changed and how it was verified.
- [tasks.md](tasks.md): the task pool, open items and items pending a decision.
- [adr/](adr/): architecture decision records, one decision per file.
- [architecture.md](architecture.md): the map of the owned system.

Run every check with `dev_tools/check.sh` (see ADR 0004).
